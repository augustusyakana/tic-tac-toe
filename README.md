# Tic Tac Toe 🎲
This is a simple Tic Tac Toe game built as part of The Odin Project curriculum. The game allows two players to take turns placing their marks on a 3x3 grid, following standard Tic Tac Toe rules.

Features:
✅ Player vs. Player mode
✅ Win detection and game reset
✅ Interactive UI with a clean design
✅ Built using HTML, CSS, and JavaScript

This project helped reinforce JavaScript fundamentals, DOM manipulation, and game logic implementation. Feel free to explore, modify, or improve it!
